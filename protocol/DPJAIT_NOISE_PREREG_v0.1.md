# 预注册协议：DPJAIT 上把逐时刻噪声当旋钮 — v0.1

状态：**v0.1，冻结前定稿**。冻结（`src/dpjait_noise_runner.py freeze`）写入本文件与 5 份源码的 SHA-256 及源码快照；此后任何改动须另立版本号，旧版本的预测照常评分并报告。

目的：检验稿件核心机制的**受控**版本——"Goldilocks 点 m\* 是有符号采样偏差的过零点，其位置由逐时刻观测噪声决定"。目前这一条的证据是**偶然的**（仿真 S10_D6 恰好比 S09_D6 噪声大 4.3 倍）。本协议在**同一批轨迹、同一参考、同一几何**上，只改观测噪声，看 m\* 是否按预测移动。

与 TIM 投稿的关系：TIM 作者须知对"仅用已有数据集、缺少实验验证正当理由"的稿件不送审直接拒。本协议**不能**替代自采实验（见 `RIG_D_SELFBUILT_DESIGN_v0.1.md`），但把公开数据上的工作从"分析发布方的检测框"推进到"从原始视频自建观测链 + 受控扰动实验"。

## 1. 被测量与装置

同 DPJAIT v0.1 §1：单架无人机参考点在窗内的轨迹弧长。真实组参考 = Vicon 十字质心 100 Hz 折线；仿真组参考 = `dronN_pos_25.csv` 的 25 Hz 折线。**两组参考率不同，不并表**，按"族"分别判定：真实族（8 条记录合并）、S11、S12、S13 各为一族。

- 真实组：R05_D1、R06_D1、R07_D1、R08_D1、R09_D1、R10_D1、R11_D1、R16_D1_A（均 4 路）。R18_D1_A 只有 3 路，排除。
- 仿真组：S11_D4、S12_D3、S13_D3（均 4 路，多机）。

## 2. 二维观测：自建检测器（替代发布的 YOLO 框）

`src/own_blob_observer.py`：

- 每路相机取全片均匀分布的 60 帧做逐像素中值背景（相机静止、目标运动，目标从中值中消失）。
- 每帧、每个下采样因子 s ∈ {1, 2, 4, 8}：对等比下采样的帧与背景取绝对差，按尺度阈值（25/20/15/12 灰度）二值化；s ≤ 2 时先 3×3 开运算；再按尺度做闭运算（9/5/3/0 像素）以合并细臂无人机被阈值切碎的碎片；取连通域中面积最大的 16 个，面积下限 30/10/4/2 像素；强度加权质心映射回全分辨率像素（$x_{\rm full}=(x_s+0.5)s-0.5$，有单元测试）。
- **不读参考。**

**参数来源（开发集）**：R02_D1 前 600 帧、S07_D8 前 300 帧。未加闭运算时，R02_D1 两路相机在 s=1 下有 13–16 % 的帧落在身份门外且为粗差（p95 200–645 px），原因是碎片面积排不进前列；加闭运算后门内率 96.7–100 %。仿真门内率 83–100 %（8 机互遮）。

## 3. 身份绑定、三角化、估计器、失败策略

- **身份**：每帧、每架无人机，取离**参考位置投影**最近、且在 **60 px** 门内的光斑（与 DPJAIT v0.1 标注臂同一规则；参考只用于决定"哪个光斑是哪架"，位置取自我们自己的光斑质心）。
- **三角化**：全部 4 路中该帧绑定到的视角做线性 DLT，≥ 2 视角，且在全部所用相机前方；否则该帧缺失。
- **估计器**：折线长度（polygon）。
- **失败策略**：窗首或窗尾时刻缺失、或可用时刻 < 2 → 该窗在该 (m, 条件) 下失败，入分母、不入误差统计。

## 4. 窗、网格

- **主窗**：T = 400 帧 = **16 s**，从第 0 帧起不重叠切分。改用 16 s 的原因：DPJAIT 在 4 s 窗下 m\* ≈ 6，一加噪就撞到网格下限 4；$m^*\propto T$，16 s 把原生 m\* 抬到约 15–25，给噪声阶梯留出下降空间。
- **主网格**：m ∈ {4, 5, 6, 8, 10, 12, 14, 17, 20, 24, 28, 34, 40, 50, 60, 80, 100, 134, 200, 400}，时刻 = $f_0+\mathrm{round}(\mathrm{linspace}(0,T,m))$ 去重。
- **资格**（参考无关）：16 s 窗合格 ⇔ 其 4 个 4 s 子窗均满足 DPJAIT v0.1 §3 的二维运动代理 ≥ 75 px。
- **对照窗**（只用于 H5）：T = 100 帧 = 4 s，DPJAIT v0.1 网格 {4, 6, 8, 10, 13, 17, 20, 25, 34, 50, 100}，同一资格规则，真实组、原生条件。

## 5. 两条噪声阶梯

- **阶梯 A（GUM 补充件 1 式扰动，主旋钮）**：s = 1；在**身份绑定之后**，对每个绑定的二维观测独立加各向同性高斯噪声，标准差 σ_add ∈ {0, 4, 8, 16, 32, 64} 全分辨率像素；σ_add > 0 时 4 个重复，种子 `default_rng([20460925, 记录序号, 档序号, 重复号])`。先绑定后加噪，因此噪声不影响身份。
- **阶梯 B（下采样，真实但弱的旋钮）**：σ_add = 0，s ∈ {1, 2, 4, 8}（s = 1 即阶梯 A 第 0 档）。

**开发集上的方向（决定了 H4、H5 的写法）**：R02_D1 前 600 帧上，自建链逐轴三维离散 s=1 为 45.8 mm，s=4 为 36.5 mm，s=8 为 35.3 mm——**下采样使噪声变小**（合并碎片、质心更稳），与"分辨率越低噪声越大"的直觉相反；阶梯 A 有效：+8 px → 54.3 mm，+32 px → 128.0 mm。另外，自建链的原生噪声（45.8 mm）高于发布 YOLO 链在确认记录上的 13.6–26.1 mm。

## 6. 评分时才计算的量

- **参考路程**：每 (无人机, 窗) 的参考折线长度。误差 = 估计 − 参考。
- **σ_a（逐轴逐时刻误差尺度）**：每个 (阶梯, 档)，把稠密三角化点与同帧参考位置相减，**逐窗减去均值向量**（去掉力臂这类共同平移），取全部残差分量的均方根。族内对记录取平均。
- **κ、v**：参考轨迹逐窗中位曲率（5 点平滑后 $|r'\times r''|/|r'|^3$）与平均速度；族内取中位。
- **m\***：族内、每档，逐 m 的**平均**绝对窗误差的最小点（主统计）；中位统计同时报告。
- **过零点**：逐 m 的**平均**有符号误差由负转正处，按 log m 线性插值。
- **闭式预测**：$\hat m^* = (T/{\rm s})\sqrt{\kappa v^2/(7\sigma_a)}$，T = 16 s。
- **删失**：m\* 落在网格端点（4 或 400）记为删失。

## 7. 预注册假设

全部在阶梯 A（H1–H3）、阶梯 B（H4）、对照窗（H5）上按族评估。

- **H1（幂律）**：在每个族内，对阶梯 A 未删失的档（≥ 4 档才可评），拟合 $\log m^*$ 对 $\log\sigma_a$ 的斜率。**通过** ⇔ 真实族斜率 ∈ [−0.70, −0.30]，**且** 3 个仿真族中 ≥ 2 个在该区间。（理论 −0.5。）
- **H2（闭式公式）**：在全部 (族 × 阶梯 A 档) 单元上，$\hat m^*/m^* \in [2/3, 3/2]$ 的比例 **≥ 70 %**。
- **H3（过零点）**：在有过零点的单元上，过零点/$m^*$ ∈ [2/3, 3/2] 的比例 **≥ 80 %**；若有过零点的单元不足一半，判为**不可评**。
- **H4（下采样方向，开发集给出）**：真实族 σ_a(s=8) ≤ 1.05 × σ_a(s=1)。
- **H5（两条观测链，同一批 4 s 窗）**：自建链（开发集上噪声更大）的 m\* **不高于**发布 YOLO 链在 DPJAIT v0.1 确认中的 m\*（R05 6、R06 4、R07 4、R08 6、R09 10、R10 10、R11 8、R16_A 6），在 **≥ 6/8** 条记录上成立。

**对稿件的含义**
- H1、H3 通过 → 稿件 V-C 节从"三条仿真记录的事后观察"升级为"受控扰动下的幂律"，并写明 −1/2 指数。
- H2 通过 → 第 VI 节设计程序的闭式公式有了前瞻证据（在注噪档上是真正的样本外预测）。
- H1 不通过而 H3 通过 → 保留"过零点定 m\*"，撤回"σ^(−1/2)"的具体指数。
- H3 不通过 → 稿件核心机制主张须降格，重写 V-B/V-C。
- H4、H5 只影响观测链一节。

## 8. 执行顺序与封存

1. `freeze`：本文件与 `src/dpjait_noise_runner.py`、`src/own_blob_observer.py`、`src/dpjait_record.py`、`src/dpjait_sim_record.py`、`src/dpjait_prereg_runner.py` 的哈希与快照。**在对任何确认记录运行 `observe` 之前完成。**
2. `observe`：原始视频 → 光斑缓存（不读参考）。
3. `predict`：身份绑定（读参考**位置**）、两条阶梯、稠密三角化、全部窗与 m 的路程**估计值**；预测 JSON 与稠密点文件的 SHA-256 写入 `seal.json`。**此步不计算任何参考路程**（运行器与测试双重保证）。
4. `score`：参考路程、σ_a、κ、v。封存文件被改动则拒绝评分。
5. `decide`：H1–H5，写 `decision.json`。
6. 报告：`reports/DPJAIT_NOISE_PREREG_RESULT_<date>.md`，全部档、全部族、删失与失败率照列。

## 9. 明确不做的事

- 不在确认数据上调检测器参数、身份门、窗长、网格、噪声阶梯、种子或阈值。
- 不用参考轨迹选窗、选帧、选光斑位置（参考只决定身份）。
- 不把失败窗从分母中去掉。
- 不把真实族与仿真族并表。
- 不训练或使用任何学习型检测器（本版只用 CPU 方法）。
